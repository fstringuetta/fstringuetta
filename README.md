## 👨‍💻 About Me

Offensive Security professional focused on identifying, exploiting, and understanding security vulnerabilities across modern applications and corporate infrastructures.

My work involves hands-on penetration testing, vulnerability research, attack-chain development, and security assessments.

I enjoy building custom security tools, automating repetitive tasks, exploring new attack techniques, and sharpening my skills through Capture The Flag (CTF) challenges.

## 🎯 Areas of Expertise

- **Web Application Security** — Authentication, authorization, injection vulnerabilities, business logic flaws, and access control.
- **API Security** — REST APIs, GraphQL, OWASP API Top 10, and cross-tenant security testing.
- **Mobile Security** — Android application assessments, reverse engineering, and runtime instrumentation.
- **Internal Penetration Testing** — Network enumeration, exploitation, privilege escalation, and lateral movement.
- **Active Directory Security** — AD enumeration, misconfigurations, credential attacks, and attack-path analysis.
- **Security Research** — Vulnerability analysis, exploitation techniques, and proof-of-concept development.
- **Security Automation** — Custom tools and scripts to improve offensive security workflows.
